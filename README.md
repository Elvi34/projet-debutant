# Mon projet

Mon projet est une application conçue pour aider les utilisateurs à organiser et suivre leurs tâches quotidiennes. Il offre une interface simple et un ensemble de fonctionnalités pour une gestion efficace du temps. 

## Objectifs du projet

- **Objectif 1** : Permettre la gestion des tâches avec des fonctionnalités de création, modification et suppression.
- **Objectif 2** : Offrir un suivi en temps réel de l'avancement des tâches et permettre de marquer les tâches comme terminées.
- **Objectif 3** : Créer une interface simple, intuitive et agréable à utiliser pour les utilisateurs de tous niveaux.
